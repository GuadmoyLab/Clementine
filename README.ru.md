# Clementine

**Конвертер файлов прямо там, где вы перетаскиваете.** Радиальное меню появляется под курсором: выберите формат, и файл конвертируется рядом с оригиналом. Всё выполняется локально: без загрузок и облака.

*[English version → README.md](README.md)*

Ядро на Rust + интерфейс на Qt 6 / QML (через [cxx-qt](https://github.com/KDAB/cxx-qt)). Linux (X11, Wayland) и Windows.

> **Статус: рабочий прототип.** Ядро конвертации покрыто тестами. Порт для Windows и запуск по Shift-перетаскиванию на X11 написаны, но ещё не проверены на реальных системах. См. [Поддержка платформ](#поддержка-платформ).

## Что умеет

Меню подстраивается под файл, на который вы указали:

| Файл | Конвертировать в | Дополнительно |
|---|---|---|
| Изображение | JPG, PNG, WebP, AVIF, HEIC, BMP, TIFF | В PDF, изменение размера (75 / 50 / 25 %, ширина 1920 / 1280 / 800 px) |
| Видео | MP4, MKV, WebM, MOV, AVI, GIF | Кадр (PNG/JPG/WebP), извлечь аудио, **обрезка**, **нарезка на несколько именованных фрагментов сразу** |
| Аудио | MP3, FLAC, WAV, M4A, OGG, AAC, OPUS | |
| PDF | Изображения (JPG/PNG), текст | Разделить, сжать |
| Документ / таблица / презентация | PDF, DOCX, DOC, TXT, RTF, ODT, HTML, EPUB, XLSX, CSV, ODS, PPTX, ODP … | |
| Архив | ZIP, 7Z, TAR, TAR.GZ, TAR.XZ | Распаковать здесь |
| Любой файл | | Копировать файл / путь / имя, дублировать, SHA-256, создать архив |

- **Пакетная обработка:** выберите несколько файлов, и действие применится ко всем; одна полоска прогресса и общий итог.
- **Нарезка на фрагменты** (видео → *More*): заполните до 8 строк «с – по – название», и все фрагменты вырезаются за один раз рядом с оригиналом (или в вашей папке результата). Время: `90`, `1:30`, `0:01:30.5`; пустое «по» = до конца; пустое название = `film-clip2`. Все строки проверяются до того, как создан первый файл.
- **Работа в фоне с прогрессом и отменой** (✕ или Esc). Для FFmpeg показываются реальные проценты.
- **Настройки** (кнопка-шестерёнка): папка результата, «оставить оба» / «перезаписать», качество изображений, офисный пакет (LibreOffice / OnlyOffice / авто), язык. Хранятся в TOML: `~/.config/clementine/config.toml` (на Windows `%APPDATA%\Clementine\config.toml`).
- **Язык:** английский и русский, по языку системы, если не задано в настройках.
- **Офисные документы** конвертируются через LibreOffice (`soffice`) и/или `x2t` из OnlyOffice, что установлено.

## Поддержка платформ

| Платформа | Как запускается меню | Проверено |
|---|---|---|
| **KDE Plasma 6 (Wayland)** | Правый клик в Dolphin → *Convert with Clementine*; глобальная клавиша **Meta+Shift+C** (берёт файлы, скопированные в Dolphin, или открывается пустым, чтобы перетащить файл на меню); `clementine <файлы>` | Да, на Plasma 6.7 |
| **Linux X11** | Удерживайте **Shift** и тащите файл: меню появится под курсором, отпустите файл на него. Запуск `clementine` без аргументов (фоновый режим). Также `clementine --menu` | Запускается и опрашивает указатель; настоящее перетаскивание не проверено |
| **Windows 10/11** | Тот же триггер Shift + перетаскивание; действие в контекстном меню Проводника | Код написан, **ещё не компилировался и не запускался** |
| GNOME и другие Wayland | Только `clementine <файлы>` | Работает как обычное окно; интеграции с рабочим столом пока нет |

Почему на Wayland нет Shift-перетаскивания: композиторы намеренно не позволяют приложениям следить за указателем и перехватывать перетаскивание глобально. В KDE маленький KWin-скрипт ставит окно под курсор, а запускают его горячая клавиша и действие Dolphin.

## Требования

Сборка: Rust (stable), Qt 6 с файлами разработки QML/Quick (`qmake6` в `PATH`), компилятор C++.
На Windows: набор MSVC, Qt 6 для MSVC, Visual Studio Build Tools.

Внешние программы (для каждого типа конвертации своя; если нужной нет, будет понятная ошибка, остальное работает):

| Для чего | Программа |
|---|---|
| Изображения | ImageMagick (`magick`) |
| Аудио / видео | FFmpeg (`ffmpeg`, `ffprobe`) |
| PDF | Poppler (`pdftoppm`, `pdftotext`, `pdfseparate`), Ghostscript (`gs`) |
| Архивы | `bsdtar` (libarchive; `tar` в Windows 10+) |
| Офисные документы | LibreOffice **или** OnlyOffice Desktop Editors |
| Копирование файла в буфер / горячая клавиша с файлами из буфера (Linux) | `wl-clipboard` (Wayland) или `xclip` (X11) |

Пример для Arch Linux:

```bash
sudo pacman -S rust qt6-base qt6-declarative imagemagick ffmpeg poppler ghostscript libarchive wl-clipboard
```

## Сборка и установка

```bash
./build.sh            # release-бинарник: target/release/clementine
./install.sh          # установка в ~/.local (бинарник, ярлык, иконка, интеграция с KDE на KDE)
./install.sh --uninstall
```

`PREFIX=/usr/local sudo -E ./install.sh` ставит на всю систему (без пользовательской интеграции с KDE).

На KDE установщик также добавляет KWin-скрипт, действие Dolphin и горячую клавишу **Meta+Shift+C** (меняется в *Параметры системы → Сочетания клавиш → Clementine*). Поставить или обновить только часть для KDE: `integration/kde/install.sh [путь/к/clementine]`.

### AppImage (Linux x86_64)

```bash
packaging/appimage/build.sh     # -> dist/Clementine-<версия>-x86_64.AppImage
```

При первом запуске скрипт скачивает [linuxdeploy](https://github.com/linuxdeploy/linuxdeploy) и его Qt-плагин в `packaging/appimage/.tools` (нужны `curl` и сеть). В образ входит Qt, работает на X11 и Wayland. Конвертеры (FFmpeg, ImageMagick, …) **не** упакованы: они берутся из системы, поэтому установите их по списку в [Требованиях](#требования). Для интеграции с KDE передайте путь к AppImage: `integration/kde/install.sh путь/к/Clementine-*.AppImage`.

Windows (PowerShell): `.\build.ps1` собирает и упаковывает Qt в `dist\Clementine`; `.\install.ps1` ставит для пользователя с ярлыком в меню «Пуск» и действием в контекстном меню Проводника (`-Uninstall` удаляет).

Запуск без установки:

```bash
cargo run --release -- /путь/к/file.png
```

## Как пользоваться

1. Укажите файл (как запускается меню в вашей системе, см. [Поддержка платформ](#поддержка-платформ)).
2. Наведите на сектор: список откроется с ближайшей к нему стороны.
3. Нажмите формат или действие. Результат появится рядом с оригиналом (или в вашей папке результата) с именем `имя-2.ext`, если имя занято.
4. Esc или клик вне меню закрывают его; Esc во время работы отменяет задачу.

## Структура проекта

```
src/convert.rs     ядро конвертации: форматы, прогресс и отмена FFmpeg, офисные бэкенды, действия (без UI)
src/settings.rs    настройки в TOML
src/bridge.rs      мост Rust ↔ QML (фоновый поток, сигналы, сообщения на языке интерфейса)
src/trigger.rs     глобальное положение указателя для Shift-перетаскивания (X11 / Windows)
qml/Main.qml       радиальное меню, списки, формы, анимации
integration/kde/   KWin-скрипт, действие Dolphin, установщик
build.sh install.sh build.ps1 install.ps1
packaging/appimage/ скрипт сборки AppImage и desktop-файл
```

Конвертер не зависит от интерфейса, поэтому интеграции с платформами можно менять, не трогая код конвертации.

```bash
cargo test    # нужны magick, ffmpeg, pdftoppm, gs, bsdtar
```

## Известные ограничения

- Объединение PDF и PDF → DOCX пока не реализованы (в меню показаны приглушённо).
- Тип файла определяется по расширению, а не по содержимому.
- «Быстрая» обрезка режет по ключевым кадрам (начало может сместиться на секунду-две); «точная» перекодирует.
- Вывод PDF/HTML/DOC через `x2t` из OnlyOffice ограничен; для полного набора установите LibreOffice.
- AppImage только для x86_64 (собирается самостоятельно, готовых релизов пока нет); пакетов Flatpak / MSI пока нет.
